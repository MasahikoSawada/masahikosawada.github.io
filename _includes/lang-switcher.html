{%- comment -%} lang-exclusive keeps each post out of the builds for the other languages, so a post only has a counterpart when it is explicitly marked translated. Linking to the same path regardless would 404 on the 48 Japanese-only articles, so those send the reader to the other language's home instead. Pages carry no lang and are built for every language, so they keep their path. static_href stops polyglot rewriting these into the language being built, which would otherwise turn the "switch language" link into a link to the current one. {%- endcomment -%} {%- for lang in site.languages -%} {%- assign label = site.data[lang].l10n.lang_name -%} {%- if lang == site.active_lang -%} {{ label }} {%- else -%} {%- if page.lang and page.translated != true -%} {%- assign target = '/' -%} {%- else -%} {%- assign target = page.url -%} {%- endif -%} {%- if lang == site.default_lang -%} {%- capture href %}{{ target }}{% endcapture -%} {%- else -%} {%- capture href %}/{{ lang }}{{ target }}{% endcapture -%} {%- endif -%} {{ label }} {%- endif -%} {%- endfor -%}
